# Standards and Documentation Links

Primary sources for looking up more than these reference files say. Start with the row that matches the pattern, cite what you read (see `citing-wcag.md` for the rules and the source tiers), and open the link when a reference file has no answer or you need the exact wording of a requirement. Links were checked on 2026-11-09 and can move, so search the site by title if one fails.
